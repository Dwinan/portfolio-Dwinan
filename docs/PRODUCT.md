# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS/JS (existing codebase, no build tool)

## Users

Recruiters, engineering leads, and collaborators evaluating a software engineer's work; primary job is scanning projects, stack, experience, and contact details on desktop, tablet, or mobile.

## Product Purpose

A single-page Swiss editorial portfolio that proves M. Faqih Dwinanda can design and engineer full-stack web systems and browser tools, with working links to live work and source repositories.

## Positioning

Distinctive, fast, dependency-free static portfolio pairing Swiss editorial dual editions (Obsidian Mist / Archival Paper) with verifiable GitHub engineering evidence and smooth performance on low-spec mobile devices.

## Operating Context

Direct URL visits and link previews; visitors explore sections (`About`, `Experience`, `Projects`, `Education`, `Contact`), filter stack items, run the Morse FSM decoder, toggle editions, copy contact email, and open repository links.

## Capabilities and Constraints

- No build step, framework, or package manager.
- Self-hosted assets only (`Geist`, `Geist Mono`, optimized WebP/JPEG portrait, local WebGL gradient engine strictly gated to capable desktop viewports).
- Purpose-built 3-state layout across desktop, tablet, and mobile (`<= 640px`) with >= 44px interactive tap targets.
- WCAG AA+ verified text and interactive border contrast in both Obsidian Mist and Archival Paper modes.
- Zero AI micro-slop definitions, zero fabricated claims, zero em dashes.

## Brand Commitments

Name: M. Faqih Dwinanda. Voice: concise, direct, engineering-focused, backed by real GitHub repositories and academic/organizational records.

## Evidence on Hand

- `DESIGN.md`: Swiss editorial visual system, dials, tokens, and contrast verification.
- `index.html`: semantic layout, 4 verified GitHub projects (`Eventory`, `MoonlightPDF`, `ArtSpace`, `Morse Code Translator`), experience, stack matrix, education, and contact.
- `css/style.css`: Obsidian Mist and Archival Paper tokens, device-gated motion/blur, and 3-state responsive grids.
- `js/main.js`: edition switcher, gated desktop WebGL mist, scroll tracking, stack category filter, opt-in Morse FSM decoder, focus-trapped mobile menu, and clipboard copy.
- `assets/images/dwinan.jpg` & `assets/images/dwinan.webp`: hero portrait assets.

## Product Principles

- Strong editorial character without bloated filler prose or heavy runtime loops on mobile.
- Instant initial paint with static CSS gradients, self-hosted preloaded fonts, and zero scroll-reveal opacity blocking on phones.
- Full keyboard accessibility, visible focus indicators, and thumb-friendly mobile layout.

## Accessibility & Inclusion

Skip-to-content link, visible focus rings, semantic landmarks, >= 44px tap targets, contrast >= 4.5:1 for text and >= 3.0:1 for interactive borders in both editions.
